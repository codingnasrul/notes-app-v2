# notes-app-v2
[IDCAMP] SUBMISSION PROJECT 

<h3>Notes App Integration with RESTful API</h3>

Proyek ini telah diperbarui untuk mendukung:
1. Integrasi API: Menggunakan https://notes-api.dicoding.dev/v2. 
2. Webpack: Menggunakan html-webpack-plugin, webpack-dev-server, dan konfigurasi build production.
3. Fetch API: Komunikasi data asinkron. 
4. Loading Indicator: Menggunakan Web Component kustom.

Fitur Opsional:
- Arsip dan Batal Arsip Catatan.
- Feedback Error dengan SweetAlert2.
- Animasi halus dengan Anime.js.

Cara Menjalankan Secara Lokal
1. Ekstrak file atau siapkan folder proyek.
2. Jalankan npm install untuk mengunduh dependencies.
3. Jalankan npm run start-dev untuk mode pengembangan.
4. Jalankan npm run build untuk menghasilkan folder dist siap produksi.
